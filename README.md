# italian-organizations-ipa-vocabulary

Each Italian public administration is assigned a unique alphanumeric
code (codice IPA) by [IndicePA](https://www.indicepa.gov.it/), the
national registry of public bodies. The code is the standard identifier
used across Italian e-government systems to uniquely refer to a public
body. This repo tracks the full list, updated automatically from the
IndicePA open data feed.

## Format

`ipa-codes.txt`: one code per line, sorted
